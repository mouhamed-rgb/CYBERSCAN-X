# CYBERSCAN X

Cyberpunk-themed Flutter starter app for Android.

## Included in this package
- Arabic RTL-friendly security dashboard
- Local URL-format validation (not a reputation or malware scan)
- File-scanner preparation screen (no file upload in this version)
- In-session scan history
- Security awareness tips
- GitHub Actions workflow to build a release APK in the cloud

## Important
This first version does not claim to detect malware, phishing, or malicious files. The URL tool only checks URL syntax locally. A real scanning service and a secure backend must be integrated before presenting threat verdicts or uploading files.

## Apply these files
Create a Flutter project first with `flutter create cyberscan_x`, then copy/merge the contents of this package into that project, replacing files when prompted. Keep the `android/`, `ios/`, and other platform folders generated by Flutter.

## Build on GitHub
Push the complete project to a GitHub repository. Open **Actions**, select **Build CYBERSCAN X APK**, and run the workflow (or push to `main`). Download `cyberscan-x-release-apk` from the successful workflow run's Artifacts section.
